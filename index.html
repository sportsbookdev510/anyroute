Features / what a route tells you

Everything a call should come with.

Routing, payments, proof and privacy in one layer. Keep your SDK; get a receipt, a budget and a choice of how to pay.

01
Anyroute

The open routing layer

Any model, any provider, any route. One familiar API for your next generation of agents. Know where every call goes and what it costs, down to the receipt.

02
Open API

Familiar request shapes

Keep the clients and request shapes your team already knows. Change the base URL and key, with OpenRouter-compatible routing preferences built in.

03
USDG credits

Prepaid, with a 0% router fee

One balance for every model and provider. Pay in USDG and withdraw what you don’t use, self-custodially.

04
Signed receipts

Portable proof per call

See the model, provider, tokens and cost behind each generation. A signed receipt travels with the response, anchored on Robinhood Chain every hour for independent verification.

05
Agent payments

HTTP 402, built for agents

A request can begin without an account. Receive a 402 quote, pay, then retry with a payment proof.

06
Agent rulebook

Rules before every request

Cap spending per request, hour, day and week. Choose models, lanes, tools and working hours. Ask first or stop the next request with a kill switch. Manage your agents.

07
Agent profiles

Choose what to publish

Opt in to public profiles with random slugs, an owner-chosen rulebook summary and the latest valid certificate. A2A-style cards and an MCP directory support discovery. Browse the directory or read profile limits.

08
Sealed agent hosting

Available for owner-built agents

Build and publish your agent sidecar image with the sealed recipe. The router verifies a registered agent’s TDX quote. No sealed agent is registered at anyroute.tech yet. Read the hosting limits.

09
Telegram approvals

Approve where you receive alerts

Link Telegram from /agents with a one-time code. Approve or deny the same single-use requests and receive alerts through AnyRoute’s bot. Approval details pass through Telegram. Link your account.

10
Encrypted chat

Encrypt on your device

End-to-end encrypted chat runs through the attested gateway. The router forwards ciphertext on this path. Other requests are read in memory to route them. Read how it works.

11
AnyRoute Network

Open for early hosts

Run the approved build in a supported Intel TDX confidential VM. Fresh attestation and host policy govern admission. Join the network, read live network statistics or inspect public host records.

12
Stock Tokens

A different way to pay

Choose a registered Stock Token and set a daily cap. Small calls accrue before a bounded swap at oracle fair value. The receipt records the exact token units allocated to each generation.

13
Fallback routing

Keep the request moving

Filter by price, latency, quantization and data policy. Unhealthy providers leave the pool, with fallbacks built in.

14
Open telemetry

Your usage, your tools

Keep usage visible across your existing systems with OpenTelemetry export and usage records.

15
Agent track record

Receipts you can inspect

Per-agent ledgers export signed receipts as CSV or JSON. Router-signed certificates use a fresh pseudonym and last seven days. They are verifiable, not anonymous.

16
Team controls

Built for shared work

Roles, budgets and access for the people building with you: one routing layer for a shared workspace.

Route types

Accountability / AnyRoute Network

A public record for every host.

The AnyRoute Network is open for early hosts running the approved build. Admission checks the hardware and policy before a host serves requests.

Automatic admission

Fresh quote, signed host policy v1 in the key log, and sanctions screening of operator and payout addresses. New hosts start on probation with a public record.

Privacy / attested routes

Privacy with a receipt.

A private request goes only to a provider whose TEE evidence was verified minutes ago. If the evidence is missing or stale, the request fails closed.

End-to-end encrypted chat

The client encrypts on your device; the attested gateway handles inference while the router forwards ciphertext.

Other request paths

AnyRoute’s router reads request text in memory to route it. Attested serving alone does not hide prompts from the router.

Evidence and stored records

Inspect signed receipts, the key transparency log and the data inventory. Receipts store hashes, token counts and cost, not prompt or answer text.

About Anyroute

Any model. Any provider.
An accountable route.

Anyroute is an open inference router for Robinhood Chain. A familiar API is the starting point. Clear payments, provider accountability and portable receipts are the reason to go further.

A route should tell you more than whether a request succeeded.

Which provider served it? What did it cost? What evidence supports its privacy claims? Who gets paid? Routing, USDG settlement, signed receipts and attestation checks run in the router, with contracts on Robinhood Chain.
