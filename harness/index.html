What the tags mean
  • Reads images. Accepts images alongside text; image input is declared by the provider.
  • Makes images. Returns images; catalogue rates may include token and image charges.
  • Audio. Accepts or returns audio; browser speech works separately from model audio.
  • Tools. Can request tool calls; the calling app must run the tools and return their results.
  • Long context. Lists a context window of at least 128,000 tokens; the chosen provider may have a lower limit.
  • Proven hardware. Has an endpoint with a fresh hardware attestation checked by the router; this does not prove answer quality or encrypt ordinary chat.
  • AnyRoute network. Has a live offer on an AnyRoute network host for a model admitted on that host; routing may choose another provider. Read more →
  • Encrypted chat. Available through the separate device-encryption gateway setup; ordinary Harness chat still sends readable requests to the router. Read more →
